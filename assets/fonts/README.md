# Pangolin (Cyrillic companion for Fuzzy Bubbles)

Fuzzy Bubbles has no Cyrillic letters, so Russian text used to switch to Onest.
Pangolin is a similar hand-written font with Cyrillic and Romanian letters; it is
listed right after Fuzzy Bubbles, so only the letters Fuzzy Bubbles lacks come from it.

Unmodified upstream files from the Google Fonts repository.
Project: https://github.com/google/fonts/tree/main/ofl/pangolin
