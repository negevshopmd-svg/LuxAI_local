LUXAI LOCAL (JARVIS) 0.4.3b — ОБНОВЛЕНИЕ 2026-11-21

0.4.3b: Исправления третьего аудита (29 пунктов). У расширения для Chrome теперь секретный ключ
связи с Jarvis (другие расширения и программы не могут с ним говорить), оно следит за одним плеером,
останавливается при закрытии вкладки и учитывает паузу и буферизацию. Напоминания «в 08:00 … 5 минут»
и «PM» в тексте понимаются правильно; вставка больше не вставляет скопированное в промежутке.
ВАЖНО: после обновления в chrome://extensions нажмите «Обновить» у расширения Jarvis.

0.4.3a: Субтитры больше не останавливаются на ошибке «COMError … Разрушительный сбой»
(кратковременный сбой звука Windows, например когда Chrome перезапускает свою аудиочасть).
Захват перезапускается сам, находит программу после перезапуска, а если не получается —
слушает весь звук компьютера. Подробности — в logs\captions_error.log.

0.4.3: При включении субтитров Jarvis спрашивает, установить ли расширение для Chrome (Да /
Позже / Больше не спрашивать). При «Да» открывается помощник: Chrome открывается, адрес
chrome://extensions и путь к папке копируются сами, а окно становится зелёным, как только
расширение заработает. Jarvis запоминает, что расширение установлено.

0.4.2z: Субтитры заранее для фильмов в браузере. С расширением Jarvis для Chrome/Edge уже
загруженная часть фильма распознаётся и переводится ДО того, как её покажут, и каждая строка
слово появляется ровно тогда, когда его произносят в фильме
(и после перемотки). Установка, один раз: Расширения → Живые
субтитры → Расширение для Chrome → Установить…, затем в Chrome включите «Режим разработчика»,
нажмите «Загрузить распакованное» и выберите папку browser_extension. Не работает с
защищённым видео (Netflix, Disney+ и т. п.) — там остаются обычные живые субтитры.

0.4.2y: В живых субтитрах новый режим «Гибрид» (по умолчанию): текст и перевод появляются
через ~1–2 секунды прямо во время речи, затем точная модель исправляет строку. Раньше
перевод появлялся только в конце фразы (до ~6 с). Тихая речь (видео с малой громкостью)
больше не теряется. В Настройках → Модель распознавания добавлена Whisper Large-v3.

0.4.2x: Документация на GitHub очищена: старые и неактуальные описания удалены,
README.md и PROJECT_HANDOFF.md переписаны под текущую версию. Сама программа не изменилась.

0.4.2w: Исправления второго аудита (50 пунктов). Вставка из истории буфера обмена больше
не может попасть в другое окно; длинные голосовые ответы читаются с начала;
«напомни через -5 минут» отклоняется, а текст напоминания больше не теряется;
GIF сохраняет настоящую длительность; окно не зависает из-за буфера обмена, уведомлений,

библиотеки возвращаются при ошибке, а Jarvis не запускается во время обновления.
У каждой копии Jarvis теперь своя задача администратора и свой автозапуск.

части), поведение не изменилось.

КАК УСТАНОВИТЬ
1. Скачайте архив с GitHub и распакуйте его в любую папку.
2. Запустите install_windows.bat — откроется окно установки (Python, библиотеки,
   OCR, локальный ИИ, офлайн-переводчик). Ничего не нужно нажимать.
3. Запустите run_windows.bat.

КАК ОБНОВИТЬ
Запустите Update.bat в папке Jarvis. Открытый Jarvis закроется сам. Окно покажет
шаги, время и скорость; в конце — «Запустить Jarvis».
Настройки, ключи, модели и папка .venv сохраняются. Копии для отката временные.

ГДЕ ЧТО ХРАНИТСЯ
config.json — настройки; .luxai_data — ваши команды, история, OCR; .luxai_secrets —
ключи (зашифрованы Windows); models — модели (не удаляются при обновлении).
