# Bundled Onest font

`Onest.ttf` is the unmodified variable font `Onest[wght].ttf` from the [Google Fonts Onest directory](https://github.com/google/fonts/tree/main/ofl/onest), downloaded on 2026-11-04. Copyright 2021 The Onest Project Authors.

It is distributed under the SIL Open Font License 1.1 in `OFL-Onest.txt`. The Qt family is **Onest**; the font includes Cyrillic and Romanian diacritics. `SOURCE-Onest.txt` preserves the source URL in runtime installations where project Markdown is omitted.
