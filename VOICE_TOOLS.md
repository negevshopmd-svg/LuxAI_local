# Голосовые инструменты Jarvis

## Открытие сайтов 18+ и файлов без лишних подтверждений

Jarvis не должен объявлять сайт «запрещённым» только из-за возрастной
тематики. Для разрешённых законом сайтов применяются **те же** правила
HTTPS-навигации, что и для YouTube: проверка URL, затем передача адреса
браузеру Windows. Сайт может самостоятельно проверять возраст или быть
недоступен в стране пользователя; Jarvis не обходит такие ограничения.

Примеры:
- **«Открой порно-хам»** (частый вариант Whisper) или **«Открой Порнхаб»**
  → передать браузеру https://www.pornhub.com/.
- **«Открой файл Отчёт.docx на рабочем столе»**
  → найти файл на Desktop по точному имени и открыть Windows-приложением,
  связанным с его расширением. Не открывать только Проводник.
- **«Открой документ Мой план в документах»**
  → найти документ по уникальному имени без расширения.
- **«Открой файл Таблица.xlsx в загрузках»**
  → открыть файл из Downloads.
- **«Нажми Enter»**, **«Нажми Ctrl+S»**
  → отправить нажатие в активное приложение, не вызывая Gemini.
  Если активно окно Jarvis, требуется сначала выбрать другое окно.
- **«Какие у тебя команды?»** → перечислить доступные функции из
  актуального каталога действий, а не выдумывать ограничения.

Если несколько файлов имеют одинаковое имя с разными расширениями,
Jarvis попросит уточнить расширение вместо случайного открытия.
Голосом не открываются произвольные пути, папки за пределами
Desktop/Documents/Downloads или неизвестные типы файлов.
Программы и скрипты (.exe/.bat/.cmd/.ps1 и др.) всё ещё требуют
явного подтверждения перед запуском.

### Подтверждения

**По умолчанию без диалога**: обычный запуск Word/Telegram, открытие
сайтов/документов, создание нового текстового файла, переименование,
Enter/Ctrl+S, изменение громкости и сохранённые безопасные макросы.

**Всегда с подтверждением**: сон/блокировка и другие действия,
влияющие на состояние системы, удаление файла в корзину,
выполняемые файлы и пользовательские команды CMD/PowerShell.
Клик по распознанной на экране кнопке «Да» также требует
разрешения, потому что неизвестный диалог может выполнять
необратимое действие.

Старая настройка confirm_desktop_actions=true не включает
больше постоянные вопросы. При желании откройте
**Настройки → Команды → Подтверждать также обычные действия**,
чтобы снова спрашивать разрешение и для безопасных операций.

### Создание голосовых команд

Скажите **«Создай новую команду»**. Jarvis спросит фразу,
затем действие. Теперь можно ответить:
**«Открой YouTube в браузере»**, **«Открой файл Отчёт.docx
на рабочем столе»**, **«Нажми Enter»**, **«Нажми Ctrl+S»**.
Эти команды сохраняются с проверенным действием и не требуют
Gemini для каждого запуска. Для последовательности из нескольких
действий, мыши, пауз, файлов и звука используйте
**Команды → Новая команда → Действия**. В разделе «Файлы»
появилось действие **«Открыть файл по имени»**.

## Время ответа Gemini: 60 секунд по умолчанию

В **Настройки → ИИ-провайдер** поле **«Время ответа облачного ИИ»**
можно менять в диапазоне **35–120 секунд**. Значение по умолчанию — 60.
Старые настройки 3–10 секунд автоматически поднимаются до 60.
Увеличение таймаута помогает при медленном ответе Gemini, **но не
снимает лимиты API** (например, HTTP 429).

## Открыть сайт по голосу без Gemini

- **«Открой Ютуб в браузере»** → откроет HTTPS-адрес youtube.com.
- **«Открой Google»** → сайт Google.
- **«Открой сайт wikipedia.org»** → указанный сайт.
- **«Открой Twitch / TikTok / GitHub / ChatGPT»** → сайт в браузере.
- **«Открой Discord»** по-прежнему означает настольную программу.
  **«Открой Discord в браузере»** откроет веб-версию.

Для известных сайтов и HTTPS-доменов Gemini не требуется. Адрес
проверяется, затем передаётся браузеру по умолчанию. Jarvis сообщает,
что **передал запрос на открытие**, но не гарантирует, что
страница загрузилась — это зависит от браузера и интернета.

## Просмотр экрана и кнопки «Да/Нет»

Jarvis может видеть локальный снимок и распознавать **реальные
кнопки Windows UI Automation**; это отдельная функция от Tesseract OCR.

1. Откройте приложение с диалогом «Да/Нет» и переключитесь в него.
2. Скажите **«Жарвис, покажи кнопки на экране»**.
3. Jarvis отобразит окно **«Экран и кнопки Windows»** с локальным
   снимком и доступными кнопками «Да/Нет».
4. Скажите **«Нажми да»** или **«Нажми нет»**, либо нажмите кнопку
   в панели. Jarvis спрашивает **дополнительное подтверждение**,
   потом активирует исходное окно и нажимает найденную кнопку мышью.

Можно также сразу сказать **«Жарвис, нажми да»**: Jarvis сначала
проверит активное окно, покажет снимок и запросит подтверждение.

На главной странице есть кнопка
**«Посмотреть кнопки на экране»**. Она использует последнее
активное окно другой программы.

**Безопасность:** Jarvis не кликает по угаданным координатам и не
нажимает «Да» в неизвестном или изменившемся окне. Он требует
**ровно одну** доступную кнопку с нужной надписью, проверяет
процесс и положение кнопки непосредственно перед действием.
Если UI Automation не поддерживается приложением (некоторые
игры, canvas, изображения, защищённые окна Windows), он
сообщает, что безопасный клик недоступен. UAC и окна
безопасности не обрабатываются. Снимки экрана **не отправляются**
Gemini или другим облачным сервисам.

Для новой функции нужен пакет pywinauto, автоматически
устанавливаемый через Update.bat. Снимок — это состояние
экрана в момент команды, **не прямая трансляция**.

## Погода без квоты Gemini

Скажите «Какая погода завтра в Кишинёве?» или «Погода завтра».
Jarvis запрашивает температуру, осадки и ветер напрямую у Open-Meteo
по HTTPS, **без вызова Gemini и без API-ключа**. Прогноз привязан к
дате и часовому поясу города; при ошибке сеть/сервис не придумывает
значения. В **Настройки → Система** можно указать город по умолчанию.

Open-Meteo: https://open-meteo.com/en/docs
Геокодинг: https://open-meteo.com/en/docs/geocoding-api

HTTP 429 у Gemini означает превышение квоты/лимита запросов.
Повторять запрос в цикле бессмысленно. Jarvis показывает причину и
задержку следующей попытки. Погода при этом использует Open-Meteo.

## Диктовка в активное окно

1. Скажите **«Включи диктовку»**, **«Начни диктовку»** или
   **«Теперь я могу тебе диктовать, а ты будешь писать»**.
2. Переключитесь в Блокнот, Word либо редактор с активным полем текста.
3. Продиктуйте текст. Он вводится локально с помощью Windows Unicode
   SendInput, без обращения к языковой модели и без буфера обмена.
4. Отдельные «новая строка», «точка» и «запятая» вставляют форматирование.
5. **«Стоп»** или **«Останови диктовку»** заканчивает режим. Упоминание
   слова «стоп» внутри обычного предложения не завершает диктовку.

Диктовка **не печатает в окне Jarvis**. Проверяйте, какое окно
активно: текст отправляется туда, где находится текстовый курсор.
Не диктуйте в пароль или терминал, если не хотите ввода в эти поля.

## Прочитать выделенный текст и сделать короткий пересказ

Текст, который вы **выделили мышью в браузере Chrome, Firefox, Word
или другом редакторе**, можно прочитать без скриншота и без
переноса в чат вручную.

1. Выделите нужный фрагмент текста мышью в браузере/редакторе.
2. Скажите **«Жарвис, прочитай выделенный текст»**
   или **«Жарвис, сделай краткий пересказ текста, который я выделил»**.
3. Jarvis временно активирует выбранное приложение, отправляет
   **Ctrl+C**, получает обычный текст из буфера обмена и восстанавливает
   предыдущие форматы буфера. Он не должен забирать старое содержимое
   буфера, если новое выделение не скопировалось.
4. Для пересказа Jarvis использует подключённый облачный AI (когда
   включён и доступен), затем локальную GGUF-модель.
   **При облачном пересказе выделенный текст передаётся вашему
   настроенному AI-провайдеру.** Для полностью локального режима
   отключите облачного помощника в настройках.
5. Если обе модели недоступны, Jarvis покажет исходное извлечение,
   не выдавая его за пересказ нейросети.

**Безопасность:** чтение требует явной команды с упоминанием выделения;
активное окно должно принадлежать другой программе (не Jarvis).
Если во время копирования изменится активное окно, выделенный текст не
будет использован. Буфер обмена с большими или несовместимыми
данными не перезаписывается. Максимум для пересказа — 6500 символов.

На некоторых защищённых страницах, в играх и в интерфейсах, где
Ctrl+C не копирует текст, потребуется обычное выделение в редакторе
или чтение всего экрана через локальный Tesseract OCR.

## Прочитать экран

Скажите **«Прочитай, что написано на экране»** либо
**«Что у меня на экране?»**. Jarvis делает локальный снимок в папке
Pictures/LuxAI и запускает **Tesseract OCR**, не загружая скриншот
в облако. Это чтение текста, не распознавание сцен или предметов.

**Ничего устанавливать вручную не нужно.** LuxAI автоматически
загружает и устанавливает проверенный SHA-256 инсталлятор
Tesseract-OCR от UB Mannheim после `Update.bat` или
`install_windows.bat`. Движок устанавливается не в Windows
Program Files, а в отдельную папку
`.luxai_data/ocr/Tesseract-OCR/tesseract.exe`.
Языковые модели **русский (rus)** и **английский (eng)**
скачиваются в `.luxai_data/ocr/tessdata`.
Версии моделей зафиксированы по GitHub commit и проверяются по
официальным Git blob хешам.

При запуске Jarvis автоматически проверяет OCR и при отсутствии
загружает его в фоновом режиме. До завершения первой установки
нужен интернет. Затем распознавание экрана работает без интернета.
Если установщик Windows потребует права администратора или
скачивание не удастся, статус ошибки появится в
**Настройки → Система → Встроенный Tesseract OCR**.
Внешний `tesseract.exe` можно выбрать вручную, но это
необязательно. Настройки, модели и пользовательские файлы
в `.luxai_data` сохраняются при обновлениях.

Официальный дистрибутив: https://github.com/UB-Mannheim/tesseract
Языковые данные: https://github.com/tesseract-ocr/tessdata_fast

## Микрофон Discord

**«Выключи микрофон в Дискорде»** предлагает отправить
Ctrl+Shift+M запущенному Discord. Это официальный переключатель:
если микрофон уже выключен, он включится после нажатия. Поэтому
Jarvis предупреждает пользователя перед подтверждением и не заявляет,
что микрофон выключен, без подтверждения состояния в Discord.
Справка: https://discord.com/blog/how-to-navigate-discord-using-only-your-keyboard

## Громкость и Windows

Громкость Windows задаётся через Core Audio и считывается с устройства
обратно. Запрос на закрытие приложения отправляется через WM_CLOSE и
не использует принудительное taskkill /F. Несохранённые документы
могут задерживать закрытие.

## Обновление

Закройте Jarvis, запустите Update.bat, затем run_windows.bat.
Локальные модели, пользовательский config.json и сохранённые команды
обновлятор не заменяет.
